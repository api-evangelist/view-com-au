# View.com.au

> Australian residential property portal operated by View Media Group Pty Ltd. View publishes no developer portal, no OpenAPI and no API program, and its web pages return HTTP 403 to every non-browser client behind DataDome bot protection — yet it runs a completely public, unauthenticated Model Context Protocol server at https://mcp.view.com.au/mcp that returns live on-market listings, agency and agent records, and off-market property data to any anonymous agent. The human web is closed to machines; the agent surface is wide open.

## How to call it

- POST JSON-RPC 2.0 to https://mcp.view.com.au/mcp
- Headers: `Content-Type: application/json` and `Accept: application/json, text/event-stream`
- No API key, no OAuth, no account, no agreement. Send no credentials — there are none to send.
- Rate limit: 100 requests per 300 seconds, signalled with `ratelimit-policy: 100;w=300`.
- Responses are `text/event-stream`; read `result.structuredContent`, not the prose `text`.
- A failed lookup returns HTTP 200 with `result.isError: true` — check `isError`, not just `error`.

## Tools

- [propertySearch](https://mcp.view.com.au/mcp): Search on-market listings by state/city/suburb/postcode/street/LGA/school or lat-long radius, filtered by property type, price, beds, baths, car spaces, land size, features and sale method (Sale/Auction/Lease/Sold). Paged via `page`; sorted via `sortBy`.
- [propertyDetail](https://mcp.view.com.au/mcp): Full listing by numeric `listingId` — address, price, description, inspection times, floor plans, Statement of Information, images, agency, agents and zoning with planning overlays.
- [offMarketPropertyDetail](https://mcp.view.com.au/mcp): Off-market ("Property 360") property by SEO slug — price estimates, zoning and planning overlays, property history, nearby schools and images.

## Optional
